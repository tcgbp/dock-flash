# Adding a dsh-market listing screenshot

This is optional (recommended, not required). The market card shows nicer with a
screenshot; without it the card still works.

## How to enable

1. Rename (or move) `screenshots.json.example` to `screenshots.json` at the
   **repository root** — next to `package.json`. This is the file the market's
   registry reads, and it reads it from *your* repository, with nothing to add
   to the awesome-dsh-plugin pull request.
2. Add your screenshot images. Recommended location: a `screenshots/` directory
   at the repo root (paths in the JSON are relative to the repo root).
3. Keep the `path` + `alt` shape shown in the example. `alt` is the accessible
   description shown on the market card.

## Editing later

You can change screenshots or add more **without another pull request** — just
commit to your own repository. The market reads `screenshots.json` from your repo
directly.

## In the awesome-dsh-plugin PR

Do **not** add screenshots or a `screenshots.json` to the PR. The submission is a
single `data/plugins/tcgbp__dock-flash.yml` file only; READMEs are regenerated by
`main` after merge.
