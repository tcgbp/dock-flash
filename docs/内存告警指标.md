内存告警指标：从 heapUsed/heapTotal 改为 RSS 绝对值 + 增长率双判据
背景
当前告警以 heapUsed/heapTotal 比值为指标，阈值 80/90/95%。V8 的 heap grow 策略会让 heapTotal 动态扩展，导致比值"稀释"、告警延迟。RSS 才是 OOM killer 和容器限制所看的指标。

新指标模型
主判据：RSS 绝对值（MB）
info: RSS ≥ 256 MB
warning: RSS ≥ 512 MB
error: RSS ≥ 1024 MB
critical: RSS ≥ 1536 MB
辅判据：RSS 增长率
RSS 线性回归斜率 > 1 MB/min 且最近 5+ 个采样点持续增长 → 额外触发 info 级告警（"RSS 持续增长中"），即使绝对值未触及阈值
增长率告警 id: host-mem-growth
heap ratio 降级为展示
告警不再使用 heapUsed/heapTotal 比值判断
配置弹窗仍展示 heap ratio 数据（进度条、数值），仅供人工参考
